LÓGICA DE PROGRAMAÇÃO NA CRIPTOGRAFIA

Vetor, matriz, função e procedimento.

As cifras da trilha usam os quatro pilares da programação.
Veja onde cada um aparece.

01 · VETOR

Uma lista de posições

Vetor guarda vários valores em posições numeradas a partir de 0. Na cifra, cada letra da mensagem vira um número de 0 a 25.

Índice012
LetraMAR
Valor12017
mensagem ← ["M", "A", "R"]
valor ← [12, 0, 17]
escreva valor[2]   // mostra 17 (R)

Atenção: a 1ª letra está no índice 0, não no 1.

02 · MATRIZ

Linhas e colunas

Matriz é um vetor de vetores. Na transposição em trilhos, cada linha é um trilho e cada coluna é uma posição da mensagem. Exemplo: PIKACHU com 3 trilhos.

Linha0123456
0P···C··
1·I·A·H·
2··K···U
grade[linha][coluna]
grade[1][3] ← "A"
// lendo linha por linha: PC + IAH + KU

Resultado: PCIAHKU. As letras são as mesmas; só a posição mudou.

03 · FUNÇÃO

Calcula e devolve um valor

Função recebe dados, aplica uma regra e retorna o resultado. Em Vigenère, ela soma a letra com a chave e ajusta para ficar entre 0 e 25.

função cifrar_letra(x, k)
    soma ← x + k
    se soma ≥ 26 então
        soma ← soma − 26
    retorne soma
fim

r ← cifrar_letra(12, 18)   // r = 4 (E)
SituaçãoContaSaída
Soma de 0 a 250 + 14 = 14O
Soma ≥ 2612 + 18 = 30 → 30 − 26 = 4E
Soma = 2625 + 1 = 26 → 0A
Negativo (decifrar)3 − 18 = −15 → −15 + 26 = 11L
04 · PROCEDIMENTO

Executa passos, sem retorno

Procedimento faz uma tarefa, como mostrar ou organizar dados, e não devolve valor. Aqui ele percorre o vetor e usa a função em cada letra.

procedimento mostrar_cifra(msg, chave)
    para i ← 0 até tamanho(msg) − 1 faça
        k ← chave[i mod tamanho(chave)]
        escreva msg[i], " + ", k, " → ",
                cifrar_letra(msg[i], k)
    fim

E DEPOIS DESTA TRILHA?

Do caderno para o mundo digital.

Explore XOR e representação binária; depois, criptografia simétrica, como AES, e troca de chaves. Investigue também hashes: eles resumem dados e não têm uma operação de decifração.

As cifras clássicas e o RSA com números pequenos deste laboratório são recursos didáticos. Para proteger dados reais, são necessárias implementações criptográficas modernas.
